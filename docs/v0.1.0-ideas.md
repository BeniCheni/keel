# v0.1.0 ideas

Ranked candidates from reviews and planning. This list is never a release scope; the PM proposes scope from it and Beni rules.

| Rank | Idea | Source (PR, pass or doc) | Rough size |
| --- | --- | --- | --- |
| 1 | Pin `actions/checkout`, `actions/setup-node` and `pnpm/action-setup` to commit SHAs instead of `@v4` tags. With `contents: read` and no secrets the blast radius is small, which is why it is an idea and not a finding. | PR #3, Pass 1 | S |
| 2 | CUSIP class against 9-digit integer-cent amounts: a random 9-digit number passes the check digit one time in ten (measured 1.39% for random 9-character alphanumerics, 0.49% for 12-character hex groups). S01's generator needs allowlist entries or a value policy before golden outputs with such values land. | PR #3, Pass 1 | S |
| 3 | The allowlist covers `fixtures/` only, so a tripwire false positive in a lockfile, a doc or a commit message has no remedy short of changing the scanner. Decide the policy before it happens. | PR #3, Pass 1 | S |
| 4 | The Linux namespace step drops the runner environment (`CI`, `RUNNER_OS`, `GITHUB_*`), so code keyed on those variables behaves differently inside the namespace than outside, as the first probe commit showed. Pass through a named set, or document the difference. | PR #3, Pass 1 | S |
| 5 | Honesty-file discovery is proved by reading vitest's printed summary. A structured reporter would not depend on its wording or colour. | PR #3, Pass 1 | S |
| 6 | `packages/core` runs `vitest` without declaring it and relies on the root's hoisted devDependency. | PR #3, Pass 1 | XS |
| 7 | The honesty-discovery test asserts the temporary file's name from pnpm's echo of its command, not from Vitest's report, so `pnpm -s test:tooling -- test-contract` fails while `pnpm verify` passes. Assert on Vitest's own output; pairs with rank 5. Beni deferred this Medium on 2026-10-31. | PR #3, Pass 2.5 | XS |
| 8 | The executive-brief template's handoff block must spell every `Co-authored-by` trailer out in full. PR #3's squash carries `Co-authored-by: Cursor <>` because the block read Cursor's address by shell substitution from a commit the merging clone had not fetched. The template lives under `.claude/skills/**`, a sensitive path, so this is a ruled change, not a drive-by. | PR #3, Pass 2.5; PR #5 | XS |
| 9 | The tripwire's email class flags every non-noreply address in a tracked file and the allowlist cannot reach outside `fixtures/`, so a vendor address such as Cursor's cannot appear in a review record. Exempt a short, reviewed list of vendor bot addresses, or extend the allowlist scope (rank 3). | PR #3, Pass 2.5; PR #5 | S |
